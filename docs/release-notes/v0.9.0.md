# PXL 0.9.0

First public release of **PXL** — annotation-driven, bidirectional binding between spreadsheets and Java objects, built on Apache POI.

Pre-1.0 release: feature-complete and fully tested, with the API still open to refinement before `1.0.0`.

## Highlights

  - **Import**: XLSX · XLS · CSV → Java objects
  - **Export**: Java objects → XLSX · XLS · streaming XLSX, plus sample-template export
  - ~30 built-in field types with custom converters, cascading cell styles, optional Bean Validation, and i18n (English/Korean)
