# PXL 0.9.3

Documentation release for **PXL** — the contributing guide now states what the repository takes: issue reports and suggestions, reviewed and applied by the maintainer.

Pre-1.0 release: documentation only, with no API or behavior change.

## Highlights

  - **Contributing policy**: `CONTRIBUTING.md` / `CONTRIBUTING_ko.md` state that the repository accepts issue reports and suggestions only — pull requests are not accepted, and the maintainer reviews each issue and makes the change
  - **Example DTOs**: the READMEs and the reference now show `@Getter` beside `@Setter` and mark which Lombok annotations PXL actually needs — accessors are for your own code, and only the no-arg constructor is required
